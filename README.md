# GPU RC4 Payload Decryption
In this repo i was adventuring on the usage of computation shader for payload decryption and the usage of the VRAM to hold the encrypted payload

> [!warning]
> This repo has no evasion tecniques implemented that may work against EDRs and other Security solution this needs to be considered as only a proof of what you can do using the GPU instead of the WinAPI or normal C programming.
